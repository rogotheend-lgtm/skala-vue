# Weather Invest

날씨와 지역별 KOSDAQ 종목을 연결한 가상투자 프로젝트

### 나만의 커스텀 추가 (과제 1번)

1. 도시 데이터 확장
- 기본 3개 도시 외에 인천, 광주, 대전 추가

2. 온도 분류 세분화
- 기존 2단계에서 녹아내림, 더움, 쾌적함, 추움 4단계로 세분화
- `v-else-if`를 활용하여 온도별 화면 표시

### 나만의 커스텀 (과제 2번)

1. 도시 관련 주식 섹터 추가
- 각 도시의 주력 산업을 반영한 주식 섹터 데이터 추가

2. `computed`를 활용한 투자 심리 추가
- 비가 오거나 기온이 20도 미만이면 시장 심리가 위축된다는 가정으로 로직 구현

3. `watch`를 활용한 리밸런싱 트리거
- 투자 심리가 변경되면 포트폴리오 변경 추천

4. 도시에 영어 이름 추가
- 한글과 영어 도시 이름으로 검색 가능하도록 구현

4.1 트러블 슈팅
- `Seoul` 검색이 되지 않아 검색어에 `toLowerCase()` 적용
- 영어 도시 이름을 소문자로 통일하여 검색 오류 해결

### 나만의 커스텀 (과제 3번)

1. 날씨 컴포넌트 분리
- 부모와 자식 컴포넌트로 분리하고 `props`, `emit`을 활용하여 데이터와 이벤트 전달

2. Element Plus 적용
- `el-card`, `el-input`, `el-button`, `el-tag`를 사용하여 날씨 화면 UI 변경

### 나만의 커스텀 (과제 4번)

1. Vue Router 적용
- 날씨 목록, 날씨 상세, Not Found 화면을 URL에 따라 분리
- `RouterLink`, `RouterView`, `router.push()`를 활용하여 페이지 이동

2. 도시 검색 상태 유지
- 검색어를 URL query에 저장하여 새로고침 후에도 검색 상태 유지

### 나만의 커스텀 (과제 5번)

1. Pinia 스토어 적용
- 날씨 단위, 도시 목록, 종목, 포트폴리오 상태를 스토어에서 관리

2. 화씨/섭씨 변경 기능 추가
- 버튼을 통해 모든 날씨 카드의 온도 단위를 한 번에 변경

3. 다크 모드 추가
- Pinia 상태에 따라 전체 화면의 다크 모드 변경

### 최종 제출

1. OpenWeatherMap API 추가
- Axios와 `async/await`를 사용하여 실제 날씨 데이터 적용
- 한글/영어 도시 검색, 전 세계 도시 추가 및 삭제 기능 구현

2. KRX API 추가
- KOSDAQ 일별매매정보를 가져와 종목명, 종가, 등락률, 거래량 표시
- 서울, 부산, 대구, 인천, 광주, 대전, 구미, 울산과 지역 기업 연결

3. 가상 포트폴리오 추가
- 가상 잔액, 보유수량, 평균매수가, 평가손익 계산
- 매수와 매도 기능 및 거래내역 추가

4. 날씨 기반 매수/매도 신호 추가
- 맑음은 매수, 악천후는 매도, 그 외 날씨는 중립으로 구분
- 중립 상태에서는 매수와 매도 모두 가능

5. 이상거래 감지 추가
- `watch`로 거래내역 감시
- 날씨 역행 거래가 같은 종목에서 1분 내 5회 발생하면 거래 잠금
- 확인창을 통해 잠금 해제

### Build & Deployment

1. 소스 코드 품질관리
- ESLint와 Oxlint 점검 결과 Error 0개
- API 키는 `.env.local`로 관리하고 Git 업로드 제외

2. Build
- `npm run build`를 통해 정적 파일 생성

3. Deployment
- Vercel SPA 새로고침 설정 추가
- GitHub Pages 자동 배포 Workflow 추가

### 실행 방법

```sh
npm install
npm run dev
```

`.env.local`

```env
VITE_OPENWEATHER_API_KEY=발급받은_키
VITE_KRX_AUTH_KEY=발급받은_키
```
